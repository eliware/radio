# Documentation

Start with the [Radio-to-Zello bridge guide](radio-server.md). It is the end-user manual for
planning, configuring, running, and troubleshooting a two-receiver installation.

The manual covers:

- Prerequisites, setup, and private channel files.
- Configuration reference and audio processing.
- Startup, recovery, health checks, and readiness responses.
- Container commands and troubleshooting.
